POWER BI · DAX REFERENCE

DAX Measures & Business Insights

Example DAX formulas for a Power BI model. These are reference snippets; the GitHub Pages demo calculates equivalent sample KPIs in JavaScript and does not execute DAX.

Total Sales

Aggregation
Total Sales =
SUM(Orders[Sales])

Calculates revenue across the current filter context.

Total Orders

Distinct count
Total Orders =
DISTINCTCOUNT(Orders[Order ID])

Counts unique order IDs in the selected data.

Average Order Value

DIVIDE
Average Order Value =
DIVIDE([Total Sales], [Total Orders], 0)

Returns average sales per order and safely handles division by zero.

Profit Margin %

Ratio
Profit Margin % =
DIVIDE(SUM(Orders[Profit]), [Total Sales], 0)

Measures profit as a percentage of sales.

Sales YTD

Time intelligence
Sales YTD =
TOTALYTD([Total Sales], 'Date'[Date])

Calculates sales from the start of the year to the current date in context.

Sales Rank

RANKX
Sales Rank =
RANKX(ALL(Orders[Region]), [Total Sales], , DESC, DENSE)

Ranks regions by sales, highest first.

SQL PRACTICE

Example: aggregate sales by region

SELECT
    region,
    SUM(sales_amount) AS total_sales,
    SUM(profit_amount) AS total_profit
FROM fact_sales
GROUP BY region
ORDER BY total_sales DESC;

This is an example query for a future warehouse model. The dashboard demo currently uses browser-side sample data, not a live SQL database.

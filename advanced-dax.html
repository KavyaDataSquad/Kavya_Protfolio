Advanced DAX Reference

Familiar with advanced DAX patterns including context transition, virtual tables, relationship control, ranking and time intelligence. This page is a standalone reference—not embedded in an individual project page.

← Back to portfolio

CALCULATE + FILTER

CALCULATE([Total Sales], FILTER(ALL(Orders), Orders[Profit] > 0))

Re-evaluates a measure under modified filter context; FILTER supplies a table condition.

SUMX

SUMX(Orders, Orders[Quantity] * Orders[Unit Price])

Iterates rows and sums an expression. Use when the required value is computed per row.

RANKX

RANKX(ALL(Orders[Region]), [Total Sales], , DESC, DENSE)

Ranks regions by the measure while removing the region filter from the ranking set.

Virtual table: ADDCOLUMNS + SUMMARIZE

ADDCOLUMNS(
    SUMMARIZE(Orders, Orders[Region]),
    "Region Sales", [Total Sales]
)

Builds a grouped virtual table and adds a calculated expression for each group.

TREATAS

CALCULATE([Total Sales], TREATAS(VALUES(RegionSelector[Region]), Orders[Region]))

Applies values from an unrelated selector table as filters to another column.

USERELATIONSHIP

CALCULATE([Total Sales], USERELATIONSHIP(Orders[Ship Date], 'Date'[Date]))

Activates an existing inactive relationship for a specific calculation.

CROSSFILTER

CALCULATE([Total Sales], CROSSFILTER(Orders[Customer ID], Customers[Customer ID], BOTH))

Changes relationship filter direction for the calculation. Use bidirectional filtering carefully.

CALCULATETABLE

CALCULATETABLE(
    VALUES(Orders[Product]),
    Orders[Profit] > 0
)

Returns a table evaluated under the specified filter context.

ISINSCOPE

IF(ISINSCOPE('Date'[Month]), [Total Sales])

Checks whether a hierarchy column is the current grouping level, useful for drill-down-aware measures.

KEEPFILTERS

CALCULATE([Total Sales], KEEPFILTERS(Orders[Category] = "Technology"))

Intersects a new filter with existing filters instead of replacing the filter on the same column.

REMOVEFILTERS

CALCULATE([Total Sales], REMOVEFILTERS(Orders[Region]))

Removes filters from the specified column/table for a comparison measure.

Rolling 12 months

CALCULATE(
    [Total Sales],
    DATESINPERIOD('Date'[Date], MAX('Date'[Date]), -12, MONTH)
)

Calculates sales over the 12-month period ending at the current maximum date.

YoY Growth %

DIVIDE(
    [Total Sales] - [Sales Previous Year],
    [Sales Previous Year]
)

Compares current sales with a separate prior-year measure. Requires a marked/valid Date table.

Dynamic title

"Sales for " & COALESCE(SELECTEDVALUE(Orders[Region]), "All Regions")

Creates a title that responds to the selected region; SELECTEDVALUE returns a fallback for zero/multiple values.

TOPN

TOPN(5, ALL(Orders[Product]), [Total Sales], DESC)

Returns the top five products by sales. Tie behaviour may return more than five rows.

COALESCE

COALESCE([Total Sales], 0)

Returns the first non-blank expression; useful for blank-safe display logic.

Advanced topics to explain in interviews

  • Row context vs filter context, and context transition through CALCULATE.
  • Measure branching, virtual tables, and iterator trade-offs.
  • ALL vs REMOVEFILTERS vs KEEPFILTERS and their impact on filter context.
  • Star-schema modelling, relationship direction, and inactive relationships.
  • Time intelligence prerequisites and performance-friendly measure design.
